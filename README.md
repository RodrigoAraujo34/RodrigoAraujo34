## 👨‍💻 Sobre Mim

Olá! Me chamo **Rodrigo Araújo Campos**.

Sou desenvolvedor de mods para **Euro Truck Simulator 2**, utilizando
**Inteligência Artificial como ferramenta de apoio no desenvolvimento**.

Meu foco é criar sistemas que adicionem:

- 🚛 Mais realismo
- ⚙️ Novas mecânicas
- 🔥 Sistemas de desgaste
- 🎮 Maior imersão
- 🛠️ Novas funcionalidades ao ETS2

Atualmente trabalho principalmente com desenvolvimento de **Plugins DLL**
para adicionar mecânicas que o jogo originalmente não possui.

# 🔥 Projetos

## 🚛 Super Aquecimento dos Freios

> Sistema de Brake Fade para Euro Truck Simulator 2.

![Version](https://img.shields.io/badge/Versão-0.3-blue?style=flat-square)
![Status](https://img.shields.io/badge/Status-Em%20Desenvolvimento-success?style=flat-square)
![Game](https://img.shields.io/badge/Jogo-ETS2-orange?style=flat-square)

O **Super Aquecimento dos Freios** adiciona uma simulação dinâmica
de temperatura e eficiência dos freios ao jogo.

### ⚙️ Recursos

✅ Aquecimento progressivo dos freios  
✅ Resfriamento automático  
✅ Perda gradual da eficiência de frenagem  
✅ Perda total dos freios em temperatura extrema  
✅ Sistema influenciado pelo peso do caminhão  
✅ Sistema influenciado pelo peso da carga  
✅ Compatibilidade com teclado  
✅ Compatibilidade com controle  
✅ Compatibilidade com volante  
✅ Compatibilidade com pedais
